# Frontier Reasoning & Hardened Intelligence Protocol

Activate this skill when solving complex architectural problems, high-stakes debugging, multi-module features, or when the user invokes `/argon` or requests frontier-grade reasoning.

## Core Directives

1. **First-Principles Thinking**:
   - Deconstruct complex requests to the bare metal. Do not accept surface-level assumptions.
   - Trace end-to-end data flows across backend, database, and client before modifying any logic.

2. **Pre-Mortem Failure Analysis**:
   - Before executing code, systematically ask: *"How will this break under high concurrency, invalid payloads, network partition, or extreme load?"*
   - Mitigate race conditions, thread safety issues, unclosed I/O streams, and memory leaks upfront.

3. **Autonomous Self-Correction**:
   - Always run the relevant tests or build scripts in the terminal after editing code.
   - If tests fail, do NOT ask the user what to do immediately — inspect the stack trace, formulate a new hypothesis, apply a surgical fix, and re-test.

4. **Zero-Assumption / Empirical Proof**:
   - Never say "This should work now".
   - Only declare completion when terminal execution shows exit code 0 or concrete validation logs.
