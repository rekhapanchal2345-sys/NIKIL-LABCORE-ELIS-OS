## 🏛️ NAVIGATION & SETTINGS DOMAIN ARCHITECTURE

Reorganize and implement the Settings Navigation into **6 Real-World Clinical Domains** with structured sub-categories:

### Domain 1: Facility, Branches & Operational Scheduling
- **Facility Identity**:
  - Hospital/Lab Legal Name, Trade Name, Clinical Establishment Act Registration Number, State Medical Directorate License No.
  - Geo-location coordinates, Branch Code, Multi-branch switcher (Head Office vs Satellite Collection Centers).
- **Operational Timings & Shifts**:
  - OPD / IPD Consultation hours, 24x7 Emergency / Trauma triage toggle, Sample Collection cutoff timings.
  - Shift Rosters: Morning, Evening, Night & On-call emergency pathologist slots.
- **Departments & Physical Units**:
  - Department Master: Biochemistry, Hematology, Microbiology, Histopathology, Molecular Biology, Radiology, Phlebotomy.
  - Physical Wards / Room Categories (for hospitals): ICU, CCU, NICU, General Ward, Private Deluxe, Daycare beds.

### Domain 2: Diagnostic & Laboratory Governance (NABL / NABH Standards)
- **Accreditation & Quality Control**:
  - NABL (ISO 15189:2022) Certificate Number, Validity Period, Scope of Testing.
  - Internal Quality Control (IQC) Rules: Westgard Rules configuration (1:2s, 1:3s, 2:2s, R:4s, 4:1s, 10x auto-hold triggers).
  - EQAS / PT (External Quality Assurance Scheme) Provider details (CMC Vellore, AIIMS, Bio-Rad EQAS).
- **Panic / Critical Value SLAs**:
  - Critical Value Alert Threshold Master (e.g., Potassium < 2.5 or > 6.5 mmol/L, Platelets < 20,000 /µL, Troponin-I elevation).
  - Mandatory Panic Value Telephonic Notification Log protocol with auto-escalation timer (15 min SLA).
  - Delta Check Thresholds (% variance from patient's previous historical report within 48-72 hours).
- **Specimen & Barcode Engine**:
  - Barcode Symbology: Code 128, GS1-128, DataMatrix 2D, QR Code.
  - Vacutainer Tube Color Code Master (EDTA Purple, Sodium Citrate Blue, SST Gold/Yellow, Fluoride Grey, Plain Red).
  - Tube volume validation & sample accessioning prefix rules (e.g., `LAB-2026-XXXXX`).

### Domain 3: Doctor, Staff & Signature/Stamp Vault
- **Digital Signatures & Stamp Vault**:
  - Dual-Signatory Sign-off logic: Junior Resident / Lab Tech preliminary entry + Senior Pathologist / MD final sign-off.
  - High-resolution encrypted digital signature & medical council seal upload with PIN/Biometric sign-off authorization.
  - State Medical Council / MCI / NMC Registration number printing on reports.
- **Granular Role-Based Access Control (RBAC)**:
  - Strict hierarchical permission matrix:
    - `HOSPITAL_SUPER_ADMIN`: Full systemic & billing override.
    - `SENIOR_PATHOLOGIST / CHIEF_BIOCHEMIST`: Clinical authorization, delta override, IQC approval.
    - `LAB_TECHNICIAN`: Result entry, analyzer batch loading (no final release privilege).
    - `PHLEBOTOMIST`: Accessioning, specimen accept/reject, barcode printing.
    - `BILLING_CASHIER`: Invoicing, receipt generation, refund requests (zero clinical view).
    - `NURSE / OPD_COORDINATOR`: Sample dispatch, patient status tracking.

### Domain 4: Billing, Tariffs, Insurance & Statutory Taxes
- **Tariff Schedules & Rate Lists**:
  - Multi-tier Tariff Master: General Walk-in, In-house IPD, Corporate Tie-ups, TPA/Cashless Insurance rates.
  - Government Scheme integration: CGHS, ECHS, Ayushman Bharat (AB-PMJAY), State Health Cards.
- **Statutory Taxes & Invoicing Rules**:
  - GST / SAC Code rules (Healthcare services under SAC 9993 - GST exempt vs taxable wellness packages).
  - PAN, GSTIN, TAN configuration, automated invoice numbering sequence with financial year prefix (e.g., `INV/26-27/0001`).
  - Maximum allowable discount percentage threshold before requiring Admin OTP/Supervisory override.
- **Payment Gateways & Hardware Terminals**:
  - Static & Dynamic UPI QR codes (NPCI compliant with invoice parameter embedding).
  - POS Machine / Card Terminal IP & Merchant IDs (PineLabs, Paytm, Razorpay POS).

### Domain 5: Medical Hardware, Interoperability & LIS Interfacing
- **Bi-directional & Uni-directional Analyzer Interfacing**:
  - ASTM E1381 / ASTM E1394 and HL7 v2.x protocol engines.
  - Supported Instrument Drivers: Mindray, Sysmex, Roche Cobas, Beckman Coulter, Horiba, Abbott Architect.
  - COM Port (RS-232), TCP/IP Socket (IP:Port), and Baud Rate/Data bits/Parity communication setup.
  - Worklist auto-query (Host Query Mode) vs batch push mode.
- **Hospital Interoperability**:
  - HL7 v2.5.1 Message handlers: `ADT_A01` (Admit), `ORM_O01` (Lab Order), `ORU_R01` (Observation Result).
  - FHIR R4 REST API endpoints for diagnostic reports (`DiagnosticReport`, `Observation`, `Patient`, `Specimen`).
  - PACS / DICOM Bridge: Modality Worklist (MWL) and Storage SCU/SCP settings for radiology reporting.

### Domain 6: Stationery, Report Header/Footer & System Security
- **Report Canvas & Pre-Printed Stationery**:
  - Header Height (mm/pt), Footer Height (mm/pt), Left/Right margins for pre-printed letterheads.
  - Full Digital PDF mode (system prints hospital logo, NABH/NABL logo, accreditation credentials) vs Pre-Printed Sheet mode (system suppresses header/footer and only prints clinical test data).
  - Dynamic Verification QR Code position (top-right or bottom footer) linking to instant verification portal.
  - Watermark controls ("PRELIMINARY REPORT", "CONFIDENTIAL", "DUPLICATE COPY").
- **Security, Compliance & Audit Trail**:
  - Immutable Audit Log: Every modification, test cancellation, discount override, or result recalculation logged with User ID, Timestamp, IP, and Previous Value vs New Value.
  - HIPAA & DISHA (India Digital Information Security in Healthcare Act) compliant idle session timeout (auto-logout at 5 / 15 / 30 mins).
  - Backup & Disaster Recovery: Automated daily encrypted database snapshot to local NAS and secondary cloud bucket (S3 / GCS), with verifiable SHA-256 integrity checks.
