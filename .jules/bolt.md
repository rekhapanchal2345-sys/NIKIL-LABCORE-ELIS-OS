## 2023-10-29 - [Eliminate N+1 Query in Pending Approvals Auto-Heal]
**Learning:** Sequential `findUnique`/`create` patterns within `for...of` loops in frequently called API endpoints like `getPendingApprovals` cause severe performance bottlenecks due to O(N) database round-trips. Prisma's N+1 query issue manifests not just in data fetching but also in data insertion patterns (upsert/create-if-missing).
**Action:** Replace sequential iterations over external input (like looping over orders and items) with bulk database operations. Use a single `findMany` with an `in` clause to check existence, filter out already existing entities in memory using a Set, and then perform bulk creations by queuing promises and executing them concurrently within `prisma.$transaction(promises)`. This reduces database round trips from O(N) to O(1).
